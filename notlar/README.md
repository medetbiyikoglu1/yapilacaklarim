# Yapılacaklarım: proje notları

Unutkanlığa karşı, işleri takvime planlayıp saatinde (ve gerekirse ısrarla) hatırlatan bir yapılacaklar uygulaması. Nihai hedef App Store'da yayınlanan bir iPhone uygulaması.

## Bağlantılar

| Ne | Nerede |
| --- | --- |
| Kod deposu | https://github.com/medetbiyikoglu1/yapilacaklarim |
| Web sürümü deneme sayfası (bildirimsiz, örnek işlerle) | https://claude.ai/artifact/LQYKHfR3JJUZPcU9zcm1UU |
| Rakip analizi (canlı doküman) | https://claude.ai/code/artifact/d2a21e21-0845-49a4-b7b7-0737ff121c83 |
| Mobil uygulama iş analizi (canlı doküman) | https://claude.ai/code/artifact/207f3d6d-5d27-4c52-9c62-068879a7dc93 |

Canlı dokümanlar Claude'da düzenlenebilir ve yorumlanabilir; bu klasördeki dosyalar onların özetidir.

## Klasör yapısı

| Klasör | İçerik |
| --- | --- |
| `notlar/` | Kararlar, analiz özetleri, mimari ve yapılacaklar |
| `public/`, `src/`, `test/`, `scripts/` | Web sürümü (PWA) ve bildirim sunucusu |
| `ios/` | iPhone uygulaması, sıradaki geliştirme (teknoloji seçimi açık) |
